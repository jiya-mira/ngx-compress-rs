# HTTP/3 benchmark evidence

The release benchmark uses `docker/http3/benchmark.sh` on the supported Linux
x86_64 baseline. It compares 4, 8, 16, and 32 KiB output buffers across HTTP/1.1,
HTTP/2, and HTTP/3, with one warm-up and at least five recorded rounds for each
4 KiB, 256 KiB, and 8 MiB compressible/incompressible payload.

The evidence set is complete only when this directory contains:

- `http3-raw.tsv`: per-request TTFB, total time, throughput, compressed size,
  and worker RSS;
- `toolchain.txt`: machine, compiler, NGINX, TLS, curl, ngtcp2, and nghttp3
  versions;
- `conclusion.md`: the deterministic gate output from `analyze.py`.

ARM or reduced-round runs are dry-runs only and must not select the production
default. The checked-in evidence is generated by the release-target x86_64 CI
runner and reviewed before the release tag. Until then, the default remains
8 KiB and no protocol-specific buffer/flush behavior is permitted.
