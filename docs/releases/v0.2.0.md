This source-only Technical Preview focuses on production correctness, bounded
event-loop work, and strict HTTP content-coding negotiation.

## Changed

- Content-coding selection now treats `identity` as a representation, honors
  explicit and wildcard quality values, rejects `q=0`, and uses server priority
  only to break equal-quality ties. A module-owned negotiation path returns
  `406 Not Acceptable` when no representation is acceptable.
- Added `compress_priority` for an explicit server tie-break prefix. Omitted
  enabled codings are completed from the active profile; child configuration
  replaces its parent value.
- Removed the `max` profile. Existing configuration that names it now fails
  validation instead of silently selecting another preset.
- Streaming compression now limits each callback to 64 KiB of input and 32
  codec steps, preserving unconsumed input and boundary state for a later
  callback. `compress_buffers` now limits both buffer size and held-buffer
  count.
- `compress_static on` shares negotiated representation ordering with dynamic
  compression. `compress_static always` remains an explicit negotiation bypass
  and emits a configuration warning.

## Fixed

- File-backed and mixed NGINX chains are materialized through a small C ABI
  shim before compression. This avoids relying on compiler-specific bitfield
  layout and fixes empty gzip, Brotli, and Zstandard bodies on ARM64.
- Transformed responses clear `Content-Length` and `Accept-Ranges`; strong
  entity tags are weakened.

## Observability

- Added `compress_stats off|variables|server_timing`.
- Added `$compress_coding`, `$compress_level`, `$compress_input_bytes`,
  `$compress_output_bytes`, `$compress_ratio`, and `$compress_time_ms`.
- `server_timing` includes those counters in a best-effort `Server-Timing`
  trailer without making trailer delivery a response requirement.

## Supported baseline

- NGINX 1.30.4, Ubuntu 24.04, Linux x86_64 and ARM64
- dynamic and static module builds
- vendored and system codec backends
- HTTP/1.1, HTTP/2, and experimental NGINX HTTP/3 without 0-RTT
- gzip, deflate, Brotli, Zstandard, and identity

Every deployment must build from source against the target NGINX binary's
exact version, configure arguments, compiler/ABI, and distribution patches. No
universal `.so` is attached.
