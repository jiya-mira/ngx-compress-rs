This source-only patch release fixes two response-path correctness issues found
after v0.1.0. The supported build baseline and public configuration remain
unchanged.

## Fixed

- `compress_static on` now emits `Vary: Accept-Encoding` whenever an applicable
  sidecar exists, including when the current client receives the identity
  fallback. This prevents shared caches from reusing an incompatible encoded
  representation.
- Recycled compression output buffers now clear stale `flush`, `sync`,
  `last_buf`, and `last_in_chain` flags before reuse, preventing unintended
  downstream flush boundaries.

## Documentation

- Replaced the premature community-interaction roadmap with an
  implementation-focused post-v0.1 development sequence.
- Recorded the intended lazy, per-location Compression Dictionary Transport
  model and the routing/update questions deliberately left for its design
  milestone.

## Supported baseline

- NGINX 1.30.4, Debian Bookworm, Linux x86_64
- dynamic and static module builds
- vendored and system codec backends
- HTTP/1.1, HTTP/2, and experimental NGINX HTTP/3 without 0-RTT
- gzip, deflate, Brotli, Zstandard, and identity

Every deployment must still build from source against the target NGINX binary's
exact version, configure arguments, compiler/ABI, and distribution patches. No
universal `.so` is attached.
