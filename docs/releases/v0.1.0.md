This is a source-only Technical Preview of a Rust NGINX response-compression
module built on the official `nginx/ngx-rust` integration layer.

## Supported baseline

- NGINX 1.30.4, Debian Bookworm, Linux x86_64
- dynamic and static module builds
- vendored and system codec backends
- HTTP/1.1, HTTP/2, and experimental NGINX HTTP/3 without 0-RTT
- gzip, deflate, Brotli, Zstandard, and identity

Every deployment must build from source against the target binary's exact
NGINX version, configure arguments, compiler/ABI, and distribution patches.
`--with-compat` does not make a universal module. No `.so` is attached.

## Highlights

- RFC-aware `Accept-Encoding` negotiation with explicit exclusions, wildcard,
  duplicate, and identity handling.
- Streaming progress validation, backpressure handling, worker-local codec
  reuse, and precompressed sidecars.
- Matching static/dynamic filter order for SSI and addition subrequests.
- Built-in `gzip on` conflict warning at `nginx -t`/startup/reload and
  request-time fail-closed behavior.
- Narrow FFI prefetch/submit boundary around safe Rust-owned policy and state.
- Pinned HTTP/3 matrix, lifecycle/fault-injection suites, ASan/UBSan, Valgrind,
  cargo-deny, CycloneDX SBOMs, and tracked-file source packaging.

## Important limitations

- NGINX HTTP/3 is experimental upstream; 0-RTT is not supported.
- NGINX versions, distributions, architectures, and configure signatures other
  than the supported baseline are unverified.
- Compression Dictionary Transport (`dcb`, `dcz`) is not included.
- Third-party filter combinations outside the release matrix are best-effort.
