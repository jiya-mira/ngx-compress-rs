## Confirmed Facts

- Production empty compressed files come from ARM ABI bitfield layout mismatch in generated `ngx_http_request_t` access, not from a codec-specific empty-stream bug.
- Server-Timing needs `expect_trailers` set before the downstream header filter and the trailer inserted before forwarding the last body buffer.
- `compress_stats off` avoids timing and byte-count collection; variables remain registered but resolve as not found without an active statistics context.
